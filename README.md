# Senzing Recipes

Build a working Senzing solution — fraud, customer 360, compliance, and more — by handing
plain-English prompts to an AI coding assistant. It does the work; **you don't write code, you
paste prompts and watch it cook.**

## Start here

**[The Senzing Cookbook](cookbook.md)** — the catalog. Pick a recipe by what you want to build.

First time? **[Get Started](getting-started.md)** covers the one-time setup: an AI coding
assistant, the Senzing MCP, and a free Senzing license. Do it once, then every recipe is
paste-and-cook.
